在“深度价值成长策略_7”（及相关分析流程）中，针对美股（usa）市场的财务数据获取，其逻辑并非直接集成在 StockStrategy 类中，而是依赖于分层的数据获取与注入机制。                                                                         
                                                                                                                                                                                                                                              
  以下是该策略获取财务数据的具体路径：                                                    
                                                                                                                                                                                                                                              
  1. 数据流向与获取机制                                                                                                                                                                                                                       
  
  StockStrategy.calculate_stock_data 是所有策略的分析入口，它本身并不直接调用任何 API 接口，而是通过参数注入的方式接收 df_financial。                                                                                                         
                                                                                                                                                                                                                                            
  - 调用层级：分析流程通常由 StockAnalysisOrchestrator 或 AnalyzeSingleStockAI 等工作流（在 src/stock_analyse/application/orchestrators/ 和 use_cases 中）发起。
  - 服务层：这些工作流会调用 AIStockDataFacade 或相关的 QuantitativeAnalysisService。
  - 基础设施层：这些服务层会调用 CompanyDataService，后者负责实际的财务数据抓取。                                                                                                                                                             
                                                                                                                                                                                                                                              
  2. 针对 usa 市场的特殊处理                                                                                                                                                                                                                  
                                                                                                                                                                                                                                              
  对于 usa 市场，财务数据获取的底层实现逻辑通常遵循以下流程：                                                                                                                                                                                 
  
  1. 统一接口：CompanyDataService 通过 MarketDataService 提供的工厂模式，根据市场标识（market='usa'）选择对应的数据提供者。                                                                                                                   
  2. 数据提供者：                                                                                                                                                                                                                           
    - 在美股环境下，系统优先使用 akshare 接口或 Futu 的相关数据接口。                                                                                                                                                                         
    - 代码中存在 ak.stock_us_spot_em() 等类似的调用（位于 FutuMarketDataProvider 或 CompanyDataService 中），负责获取基础财务指标。                                                                                                           
  3. 财务指标填充：                                                                                                                                                                                                                           
    - src/stock_analyse/application/use_cases/analyze_financials.py 会负责调度具体的财务指标获取。                                                                                                                                            
    - 财务报表数据通常会被清洗后放入 df_financial 数据框中，最终作为参数传给 StockStrategy.calculate_stock_data。                                                                                                                             
                                                                                                                                                                                                                                              
  3. 如何在策略_7中调试该数据的来源                                                                                                                                                                                                           
                                                                                                                                                                                                                                              
  如果您想追踪某只美股的具体财务数据来源，建议从以下位置切入：
