该表旨在帮助投资者根据企业所处的生命周期，选择最科学的“尺子”（估值指标）进行度量。

| **成熟期** (Mature) | 现金流质量、派息意愿 | 分红率、ROE、自由现金流 | P/E, DDM, DCF | 赚取确定的分红和盈利增长的钱 |
| **高增长期** (Growth) | 营收/利润复合增速 | PEG、营收增速、毛利率 | 远期 P/E, PEG | 赚取企业规模扩张与业绩爆发的钱 |
| **概念期** (Concept) | 行业空间、市占率潜力 | 营收增长、烧钱率、TAM | P/S, 远期 DCF | 赚取未来梦想实现后的折现价值 |
| **周期性** (Cyclical) | 供需缺口、大宗价格 | 产能利用率、库存周期 | P/B, 产能估值 | 赚取行业反转与商品价格波动的钱 |
| **防守型** (Defensive) | 业绩稳定性、低波动 | 营收波动率、Beta值 | P/E, PEG | 赚取宏观波动时的避险溢价 |
| **垃圾股** (Junk) | 净资产、重组重整预期 | 资产负债率、清算价值 | P/B, 壳价值估算法 | 赚取博弈反转或资产重组的极端收益 |

### 表格二：五阶段判断模型（时机维度）

该表用于判断当前处于价格波动的哪个时点，解决“什么时候买/卖”的问题。

| 阶段 | 核心特征 | 市场心理状态 | 关键量化信号 | 建议操作 |
| --- | --- | --- | --- | --- |
| **A 困境期** | 情绪极差、预期见底 | “这票没救了”，无人问津 | 估值分位 < 20%，价格持续破位 | 保持观察，仅限极小仓位试错 |
| **B 修复初期** | 基本面拐点出现 | “真的好转了吗？我不信” | 分析师开始上调评级，价格企稳 | **建仓期**：买入第一笔核心仓 |
| **C 修复确认期** | 趋势形成、数据共振 | “确定反转了，赶紧跟上” | 利润增速确认，成交量持续放大 | **加仓期**：确认趋势后加第二笔 |
| **D 乐观定价期** | 好消息频传、估值抬升 | “风景那边独好”，全场看好 | 股价加速上涨，利好消息已反映 | **持股期**：不轻易追高，享受涨幅 |
| **E 透支期** | 价格远超基本面 | “天空才是极限”，极度疯狂 | 估值历史极值，高换手率，滞涨 | **减仓期**：停止加仓，分批止盈 |

### 表格三：四区价格分区（空间维度）

该表通过历史分位和安全边际，确定当前价格的“赔率”与“胜率”。

| 区间 | 核心含义 | 估值位置特征 | 风险/收益比 (RRR) | 操作动作 |
| --- | --- | --- | --- | --- |
| **便宜区** | 极高赔率区 | 估值历史分位 < 25% | 赔率极高，但短期胜率可能不确定 | 底部布局，分批买入第一笔 |
| **合理偏低区** | 舒适投资区 | 估值历史分位 25% - 40% | 胜率与赔率达到最佳平衡点 | 重点配置，执行二次加仓 |
| **合理区** | 价值回归区 | 估值历史分位 40% - 70% | 性价比一般，胜率尚可 | 持股待涨，不建议大举建仓 |
| **高估区** | 风险暴露区 | 估值历史分位 > 75% | 赔率极低，容错能力极差 | 防御为主，只出不进，考虑撤退 |

---

### 综合应用逻辑提示：

* **最佳买点**：发生在 **[修复初期 (B)]** 叠加 **[便宜区/合理偏低区]**。
* **警惕陷阱**：**[困境期 (A)]** 虽处于 **[便宜区]**，但可能面临长期阴跌，需控制仓位。
* **卖出信号**：**[透支期 (E)]** 叠加 **[高估区]**，无论公司多好，都应严格执行减仓纪律。

### 1.2 量化分类公式

```python
def classify_stock_type(
    # 盈利能力
    net_profit: float,           # 净利润
    revenue: float,              # 营收
    roe: float,                  # 净资产收益率 %
    cash_flow: float,            # 经营现金流
    
    # 增长指标
    revenue_growth: float,        # 营收增速 %
    profit_growth: float,        # 利润增速 %
    
    # 分红指标
    dividend_yield: float,       # 分红率 %
    dividend_per_share: float,   # 每股分红
    
    # 规模指标
    market_cap: float,           # 市值(亿)
    free_float_ratio: float,     # 自由流通股比例
    
    # 波动指标
    revenue_volatility: float,   # 营收波动率(3年标准差)
    
    # 行业属性
    industry: str,               # 行业名称
    
    # 估值指标
    pe: float,                   # 市盈率
) -> StockType:
    """
    股票类型分类
    返回: StockType枚举
    """
    
    # ========== 1. 亏损/垃圾股判断 ==========
    if net_profit < 0:
        # 连续亏损检查
        if is_连续亏损(net_profit, periods=3):
            return StockType.JUNK  # 垃圾股
        else:
            # 暂时性亏损，可能反转
            return StockType.JUNK
    
    # ========== 2. 微利/低质判断 ==========
    if market_cap < 10:  # 小市值陷阱
        if roe < 5 or profit_growth < 0:
            return StockType.JUNK  # 垃圾股
    
    # ========== 3. 成熟期判断 ==========
    # 条件: 高分红 + 稳定盈利 + 现金流好
    mature_score = (
        (dividend_yield >= 2.0) * 0.3 +    # 分红门槛
        (roe >= 10) * 0.3 +                 # ROE门槛
        (cash_flow / net_profit >= 0.8) * 0.2 +  # 现金流质量
        (profit_growth >= -5 and profit_growth <= 20) * 0.2  # 稳定增长
    )
    
    if mature_score >= 0.7:
        return StockType.MATURE
    
    # ========== 4. 高增长期判断 ==========
    # 条件: 营收/利润高增长
    growth_score = (
        (revenue_growth >= 30) * 0.4 +
        (profit_growth >= 20) * 0.3 +
        (revenue >= 1e8) * 0.1 +  # 有一定规模
        (pe < 50) * 0.2  # 估值不极端
    )
    
    if growth_score >= 0.6:
        return StockType.GROWTH
    
    # ========== 5. 周期/防守判断 ==========
    cyclical_industries = {
        '煤炭', '钢铁', '有色金属', '化工', '石油',
        '水泥', '玻璃', '房地产', '汽车', '航运',
        '造纸', '航空', '电力设备'
    }
    
    defensive_industries = {
        '食品饮料', '医药生物', '公用事业', '银行',
        '交通运输', '建筑装饰'
    }
    
    # 周期行业 OR 营收波动大
    if industry in cyclical_industries or revenue_volatility > 20:
        return StockType.CYCLICAL
    
    # 防守行业 OR 营收稳定
    if industry in defensive_industries or revenue_volatility < 10:
        return StockType.DEFENSIVE
    
    # ========== 6. 概念期判断 ==========
    # 条件: 未盈利但有营收，且有概念/主题属性
    if net_profit <= 0 and revenue > 0:
        if is_concept_stock(industry):
            return StockType.CONCEPT
    
    # 默认按防守型处理
    return StockType.DEFENSIVE


def is_连续亏损(net_profit_series: list, periods: int = 3) -> bool:
    """判断是否连续亏损"""
    return all(p < 0 for p in net_profit_series[-periods:])


def is_concept_stock(industry: str) -> bool:
    """判断是否概念股"""
    concept_industries = {
        '半导体', '软件开发', 'IT服务', '通信设备',
        '互联网服务', '传媒', '电子元件', '新能源',
        '人工智能', '生物医药'
    }
    return industry in concept_industries
```

### 2.2 五阶段判断公式

```python
@dataclass
class StageIndicators:
    """阶段判断指标"""
    # 基本面 (0-100，越高越好)
    revenue_trend: float          # 营收趋势分
    profit_trend: float          # 利润趋势分
    cash_flow_quality: float      # 现金流质量分
    
    # 预期 (0-100，越高预期越乐观)
    market_expectation: float     # 市场预期
    analyst_revision: float       # 分析师调整 (-50~+50, 正为上调)
    price_reflects_news: float    # 价格已反映利好程度 (0-100)
    
    # 估值 (0-100，越高越贵)
    valuation_level: float        # 估值水平(历史分位)
    
    # 价格行为 (0-100，越强越好)
    price_momentum: float         # 价格动能
    volume_pattern: float         # 成交量模式
    support_strength: float       # 支撑强度


def calculate_indicators(
    financial: FinancialMetrics,
    price_data: PriceData,
    sentiment: MarketSentiment,
    historical_pe: list[float],
    historical_pb: list[float]
) -> StageIndicators:
    """计算各维度指标"""
    
    # 1. 基本面趋势分 (基于营收/利润增速)
    revenue_trend = sigmoid_transform(financial.revenue_growth, 
                                      low=-20, high=40)
    profit_trend = sigmoid_transform(financial.profit_growth,
                                     low=-30, high=50)
    
    # 2. 现金流质量 (经营现金流/净利润)
    if financial.net_profit > 0:
        cash_flow_quality = min(financial.cash_flow / financial.net_profit, 2) * 50
    else:
        cash_flow_quality = 20 if financial.cash_flow > 0 else 0
    
    # 3. 市场预期 (基于分析师评级和情绪)
    market_expectation = sentiment.analyst_rating * 20  # 1-5 → 20-100
    
    # 4. 分析师调整 (归一化到0-100)
    analyst_revision = (sentiment.analyst_revision + 50)  # -50~+50 → 0~100
    
    # 5. 价格已反映利好程度
    price_reflects_news = sentiment.price_reflects_good_news * 100
    
    # 6. 估值水平 (历史分位)
    valuation_level = calculate_percentile(
        financial.pe, historical_pe
    ) if financial.pe > 0 else calculate_percentile(
        financial.pb, historical_pb
    )
    
    # 7. 价格动能 (基于20日涨幅)
    price_change_20d = price_data.price_change_20d
    price_momentum = sigmoid_transform(price_change_20d,
                                       low=-20, high=40)
    
    # 8. 成交量模式
    volume_ratio = price_data.volume / price_data.avg_volume_20d
    if volume_ratio > 1.5:
        volume_pattern = 80  # 放量
    elif volume_ratio > 0.8:
        volume_pattern = 50  # 正常
    else:
        volume_pattern = 20  # 缩量
    
    # 9. 支撑强度
    distance_from_low = price_data.distance_from_low
    if distance_from_low < 5:  # 距低点<5%
        support_strength = 20  # 可能破新低
    elif distance_from_low < 15:
        support_strength = 50  # 试探支撑
    else:
        support_strength = 80  # 支撑有效
    
    return StageIndicators(...)


def sigmoid_transform(value: float, low: float, high: float) -> float:
    """Sigmoid变换，将值映射到0-100"""
    normalized = (value - low) / (high - low)
    return 1 / (1 + np.exp(-10 * (normalized - 0.5))) * 100


def classify_stage(indicators: StageIndicators) -> tuple[PriceStage, float]:
    """
    五阶段分类
    返回: (阶段, 置信度)
    """
    
    # ========== A: 困境期 ==========
    # 条件: 便宜但还在跌
    # 公式: 估值低 AND 盈利差 AND 价格跌 AND 预期悲观
    A_score = (
        (100 - indicators.valuation_level) * 0.2 +   # 估值低
        indicators.profit_trend * 0.15 +              # 盈利差
        (100 - indicators.price_momentum) * 0.25 +   # 价格跌
        (100 - indicators.market_expectation) * 0.2 + # 预期悲观
        (100 - indicators.cash_flow_quality) * 0.2    # 现金流差
    )
    
    # ========== B: 修复初期 ==========
    # 条件: 基本面开始改善，但市场不信
    # 公式: 盈利改善 AND 预期低 AND 分析师刚开始上调
    B_score = (
        indicators.profit_trend * 0.25 +              # 盈利改善
        (100 - indicators.market_expectation) * 0.2 + # 预期还不高
        (indicators.analyst_revision > 30 and 
         indicators.analyst_revision < 60) * 30 +     # 刚开始上调
        (indicators.valuation_level < 50) * 0.15 +    # 估值还不贵
        indicators.price_momentum * 0.1               # 价格还没大涨
    )
    
    # ========== C: 修复确认期 ==========
    # 条件: 数据越来越好，趋势稳定
    # 公式: 盈利持续改善 AND 分析师全面上调 AND 价格上涨
    C_score = (
        indicators.profit_trend * 0.2 +
        indicators.analyst_revision * 0.2 +           # 分析师全面上调
        indicators.price_momentum * 0.2 +             # 价格趋势上涨
        indicators.volume_pattern * 0.15 +            # 成交量配合
        indicators.cash_flow_quality * 0.15 +         # 现金流改善
        (indicators.valuation_level > 30 and 
         indicators.valuation_level < 70) * 0.1       # 估值合理
    )
    
    # ========== D: 乐观定价期 ==========
    # 条件: 市场普遍看好，利好大多已反映
    # 公式: 预期高 AND 估值高 AND 分析师全面看好
    D_score = (
        indicators.market_expectation * 0.25 +        # 市场乐观
        indicators.analyst_revision * 0.2 +           # 全面上调
        indicators.valuation_level * 0.25 +          # 估值已高
        (100 - indicators.profit_trend) * 0.15 +      # 盈利边际放缓
        indicators.price_reflects_news * 0.15         # 利好已反映
    )
    
    # ========== E: 透支期 ==========
    # 条件: 价格快于基本面，强弩之末
    # 公式: 估值极端高 AND 价格暴涨 AND 预期过度乐观
    E_score = (
        (indicators.valuation_level > 80) * 25 +     # 估值极端
        indicators.price_momentum * 0.25 +            # 价格暴涨
        indicators.market_expectation * 0.2 +         # 预期过度乐观
        (indicators.volume_pattern > 70 and 
         indicators.price_momentum < 70) * 20 +      # 放量滞涨
        indicators.profit_trend * 0.1                 # 盈利跟不上
    )
    
    # 取最高分
    scores = {
        PriceStage.A_DISTRESS: A_score,
        PriceStage.B_RECOVERY_START: B_score,
        PriceStage.C_RECOVERY_CONFIRM: C_score,
        PriceStage.D_OPTIMISTIC: D_score,
        PriceStage.E_EXCESSIVE: E_score
    }
    
    best_stage = max(scores, key=scores.get)
    max_score = scores[best_stage]
    
    # 置信度: 最高分与次高分的差距
    sorted_scores = sorted(scores.values(), reverse=True)
    if len(sorted_scores) >= 2:
        confidence = (sorted_scores[0] - sorted_scores[1]) / 100
    else:
        confidence = 0.5
    
    return best_stage, min(confidence, 0.95)
```

```python
# 快速判断阈值（可调参）

}

# 阶段B阈值
B_CONDITIONS = {

    'pe_percentile_max': 50,        # PE分位 < 50%
    'analyst_revision_min': 0,      # 分析师开始上调
    'price_20d_min': -10,           # 还没大涨
    'price_20d_max': 15,            # 20日涨幅 < 15%
}

# 阶段C阈值
C_CONDITIONS = {
    'profit_growth_min': 15,        # 利润增速 > 15%
    'analyst_revision_min': 20,    # 分析师持续上调
```

### 3.2 分区判断公式

```python
@dataclass
class ZoneIndicators:
    """分区判断指标"""
    # 估值指标
    valuation_percentile: float    # 估值历史分位 0-100
    industry_percentile: float     # 行业对比分位 0-100
    
    # 相对价格位置
    distance_from_low: float       # 距52周低点 % (越小越便宜)
    distance_from_high: float      # 距52周高点 % (越大越便宜)
    current_in_52w_range: float    # 在52周区间的位置 % (越小越便宜)
    
    # 情绪指标
    sentiment_score: float          # 综合情绪 -100~100
    risk_appetite: float            # 风险偏好 0-100
    
    # 宏观环境
    macro_cycle: str               # 'early'/'mid'/'late'
    interest_rate_trend: str        # 'rising'/'neutral'/'falling'


def calculate_zone_score(
    stock_type: StockType,
    indicators: ZoneIndicators,
    valuation_config: dict
) -> float:
    """
    计算综合分区得分 (0-100)
    分数越低越便宜，越高越贵
    """
    
    # 根据股票类型调整权重
    weights = get_zone_weights(stock_type)
    
    # 1. 估值分位得分 (权重最高)
    valuation_score = indicators.valuation_percentile * weights['valuation']
    
    # 2. 相对价格得分
    # 距低点越远、距高点越近，越贵
    price_score = (
        indicators.distance_from_low * weights['from_low'] +
        (100 - indicators.distance_from_high) * weights['from_high']
    )
    
    # 3. 情绪得分 (情绪越高越贵)
    sentiment_score = (indicators.sentiment_score + 100) / 2 * weights['sentiment']
    
    # 4. 宏观调整
    macro_adjustment = get_macro_adjustment(
        indicators.macro_cycle,
        indicators.interest_rate_trend
    ) * weights['macro']
    
    # 5. 行业对比调整
    industry_adjustment = (
        (indicators.industry_percentile - 50) * 
        weights['industry']
    )
    
    total_score = (
        valuation_score +
        price_score +
        sentiment_score +
        macro_adjustment +
        industry_adjustment
    )
    
    return max(0, min(100, total_score))


def get_zone_weights(stock_type: StockType) -> dict:
    """根据股票类型获取分区权重"""
    
    base_weights = {
        'valuation': 0.45,      # 估值分位权重
        'from_low': 0.15,       # 距低点权重
        'from_high': 0.15,      # 距高点权重
        'sentiment': 0.10,      # 情绪权重
        'macro': 0.08,          # 宏观权重
        'industry': 0.07        # 行业权重
    }
    
    # 不同类型调整权重
    if stock_type == StockType.CYCLICAL:
        # 周期股: 估值权重降低，价格位置权重升高
        return {
            'valuation': 0.35,
            'from_low': 0.25,
            'from_high': 0.20,
            'sentiment': 0.08,
            'macro': 0.07,
            'industry': 0.05
        }
    
    if stock_type == StockType.GROWTH:
        # 成长股: 远期估值权重更高
        return {
            'valuation': 0.40,
            'from_low': 0.12,
            'from_high': 0.12,
            'sentiment': 0.15,
            'macro': 0.10,
            'industry': 0.11
        }
    
    if stock_type == StockType.MATURE:
        # 成熟股: 分红率影响更大
        return {
            'valuation': 0.50,
            'from_low': 0.10,
            'from_high': 0.10,
            'sentiment': 0.10,
            'macro': 0.10,
            'industry': 0.10
        }
    
    return base_weights


def classify_zone(score: float) -> tuple[PriceZone, str]:
    """
    分区分类
    返回: (区间, 建议)
    """
    
    if score < 20:
        return PriceZone.CHEAP, "赔率高，可以买第一笔"
    elif score < 40:
        return PriceZone.REASONABLE_LOW, "胜率和赔率都不错，可以加第二笔"
    elif score < 70:
        return PriceZone.REASONABLE, "可持有，但不适合大举加仓"
    else:
        return PriceZone.OVERVALUED, "风险上升，停止加仓，考虑减仓"
```

### 4.2 板块调整公式

```python
def adjust_zone_by_sector(
    base_zone: PriceZone,
    base_score: float,
    sector_info: SectorInfo,
    indicators: ZoneIndicators
) -> tuple[PriceZone, float]:
    """
    根据板块信息调整分区结果
    
    调整逻辑:
    1. 周期股: 在周期底部时降低门槛，顶部时提高门槛
    2. 行业对比: 个股相对行业折价/溢价调整
    3. 宏观敏感: 高敏感板块在宏观差时更便宜
    """
    
    score = base_score
    
    # 1. 周期属性调整
    if sector_info.cycle_property == '强周期':
        # 周期股: 估值区间要宽
        if base_zone == PriceZone.CHEAP:
            score *= 0.9  # 更容易进入便宜区
        elif base_zone == PriceZone.OVERVALUED:
            score *= 1.1  # 更容易进入高估区
    
    # 2. 行业对比调整
    # 个股PE分位相对板块的分位差
    sector_adjustment = (sector_info.vs_sector_pe_percentile - 50) / 2
    score += sector_adjustment
    
    # 3. 宏观敏感度调整
    if sector_info.macro_sensitivity == '高敏感':
        # 高敏感板块: 估值区间要严
        if base_zone in [PriceZone.CHEAP, PriceZone.REASONABLE_LOW]:
            score *= 1.1  # 不容易进便宜区
        else:
            score *= 0.95  # 更容易出便宜区
    
    # 4. 主题溢价/折价
    if sector_info.themes:
        hot_themes = get_current_hot_themes()  # 获取当前热门主题
        for theme in sector_info.themes:
            if theme in hot_themes:
                score *= 1.15  # 热门主题溢价
    
    score = max(0, min(100, score))
    
    # 重新判定区间
    thresholds = ZONE_THRESHOLDS.get(
        sector_info.style, 
        ZONE_THRESHOLDS['default']
    )
    
    if score < thresholds['cheap_max']:
        return PriceZone.CHEAP, score
    elif score < thresholds['reasonable_low_max']:
        return PriceZone.REASONABLE_LOW, score
    elif score < thresholds['reasonable_max']:
        return PriceZone.REASONABLE, score
    else:
        return PriceZone.OVERVALUED, score
```
